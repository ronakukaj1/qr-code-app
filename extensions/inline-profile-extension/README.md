# Inline Profile Extension

Customer account UI extension for the Profile page loyalty rewards block.

Target: `customer-account.profile.block.render`

## Preview

1. Run `shopify app dev` from the app root.
2. Press `p` to open the Dev Console.
3. Click the preview link for `inline-profile-extension`.
4. Navigate to the customer **Profile** page.

If the block appears above the page title, add `?placement-reference=PROFILE1` to the URL to test the next placement slot.
